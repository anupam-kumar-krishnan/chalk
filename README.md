# _Chalk_

![Hero_Image](./Readme%20Assets/Hero_Image.jpeg)

Chalk is an engineering **documentation** workspace that brings **technical docs** and **architecture diagrams** together. Write documentation, visualize systems, and generate diagrams from text—all in one place.

### Chalk — Features built so far

**1. Engineering Documentation Editor
Built**

Write and present technical documentation for engineering systems, using a document about a user search system as an example.

**2. Diagram Editor
Built**

Create architecture diagrams with components, labels, icons, and connections.

**3. Three Workspace Viewing Modes
Built**

- Doc: Focus on documentation.
- Both: View documentation and the diagram side by side.
- Diagram: Focus on the diagram.

**4. Connected Documentation and Diagrams
Built — shared workspace**

Both artifacts are available in the same engineering workspace, so users can read the explanation alongside its visual representation.
